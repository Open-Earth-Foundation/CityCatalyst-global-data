# Climate project

## What a climate project is

A climate project is a funded, time-bound intervention that implements one or more climate actions in a specific place. Projects represent the realised financing landscape — concrete investments that provide evidence of how climate actions are planned, delivered, and funded in practice.

Projects answer a different question from policy signals and assessments. Where policy tells us what is prioritised and assessments tell us what is needed, projects show us what has actually been done and financed. They are the closest proxy we have for what is locally feasible and fundable.

---

## Two complementary lenses

When using project evidence to inform recommendations, two lenses apply:

**Local projects** ground recommendations in the specific financing and institutional context of the city or country in question. They show what has been implemented within existing funding pathways and delivery models, making recommendations locally credible and replicable.

**Global projects** provide evidence of how climate actions are financed beyond the local context. They surface proven financing archetypes and emerging approaches that may not yet have a local precedent, broadening the solution space.

Together these ensure that recommendations are both locally feasible and informed by global evidence.

---

## Projects as portfolios of actions

A climate project is rarely a single intervention. In practice, projects are bundles of coordinated interventions that map to multiple climate actions. A sustainable transport project might include bikeway infrastructure, bus fleet renewal, congestion pricing, and land-use policy changes — each mapping to a distinct climate action.

The correct framing is:

```
Project → intervention clusters → collection of actions
```

A project should not be classified as belonging to a single action or sector. It should be treated as a portfolio, with each intervention mapped separately to the most relevant action.

## Data requirements

### Minimum viable fields

For a project to be useful for action mapping and evidence, the following fields are required:

| Field | Purpose |
|---|---|
| Source and source ID | Traceability back to the funder or database |
| Project name and description | Classification and keyword matching |
| Geography (country, region, city) | Spatial relevance filtering |
| Sector | Broad alignment with action taxonomy |
| Total amount and currency | Financing scale context |
| Instrument type | Loan, grant, guarantee, equity, blended |
| Status | Pipeline, active, completed |

### Enrichment fields

For projects shortlisted as highly relevant, deeper enrichment adds significant value:

| Field | Purpose |
|---|---|
| Intervention model | What was built or implemented, delivery mechanisms, scale indicators |
| Institutional model | Implementing agencies, delivery partners, governance structures |
| Financing structure | Funding sources, co-financing arrangements, instrument breakdown |
| Implementation timeline | Major phases, milestones, duration |
| Performance outcomes | Quantitative targets and measured outputs |
| Implementation lessons | Documented risks, challenges, and lessons for replication |

Enrichment is typically extracted from linked project documentation — appraisal documents, program reports, official summaries — rather than from API metadata alone.

## Relationship to other concepts

- **Climate action**: a project implements one or more actions; actions are the unit of recommendation, projects are the evidence base
- **Project preparation**: the process of developing a project from early concept to bankable proposal; a distinct workflow from action prioritisation
- **Finance readiness**: the degree to which a project concept meets the criteria a funder would need to consider it; influenced by data quality, institutional credibility, and alignment with funder priorities
- **Funder profile**: each funder has instrument preferences, sector focus, geography constraints, and eligibility criteria that determine which projects they will consider
