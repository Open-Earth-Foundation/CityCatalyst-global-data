# Google Earth Engine — dataset reviews

Reviews for datasets whose **primary production access path** is [Google Earth Engine](https://earthengine.google.com/) (hosted assets, Earth Engine scripts, or zonal statistics computed in GEE).

Publisher-specific folders live here when the national initiative distributes through MapBiomas-style GEE assets rather than a single government API. Each dataset still gets its own subfolder, `releases/`, and a catalog entry in `dataset-review/catalog/index.yaml`.
