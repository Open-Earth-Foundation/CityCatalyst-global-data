# C40 High Impact Actions

Dataset review for C40's High Impact Actions framework and related materials describing city climate action interventions.

## Why we use it
- Action taxonomy that can support city action recommendation and prioritization workflows.
- Useful bridge between policy intent and implementable mitigation/adaptation actions.
- Strong relevance for HIAP-style scoring and action portfolio design.

## Current approved release
**2026** (research/review release; not production approved)
