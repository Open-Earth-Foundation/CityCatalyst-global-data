# C40 City Emissions Benchmark Context

Versioned review space for benchmark context used to interpret city emissions
values by sector and support QA checks.

## Why we track it

- **Benchmarking context** - provides expected value bands and variation drivers
  for sector-level emissions interpretation.
- **DQ support** - supplies reference logic for soft flags and investigation
  workflows in QA agent runs.
- **MCP context** - creates reusable interpretation context for future
  Global API MCP responses.

## Current tracked release

**2024** (working release; production approval tracked in `catalog/index.yaml`).
