# IDB Datastore Search API

Inter-American Development Bank (IDB) API endpoint for datastore search queries, used to discover and retrieve structured records from IDB open data resources.

## Why we use it
- **Project discovery** - identifies IDB records relevant to climate and development analysis
- **Structured API access** - supports programmatic retrieval with filters and pagination
- **Regional relevance** - strong coverage for Latin America and the Caribbean
- **Pipeline candidate** - source for future API-based ingestion workflows
