# Transition Element Framework (TEF)

Dataset review for the Transition Element Framework website and structured content describing mitigation compendium activities and transition elements.

## Why we use it
- Common taxonomy for climate mitigation actions grounded in IPCC mitigation options.
- Structured action decomposition useful for action libraries, policy/legal linking, and HIAP-style prioritisation workflows.
- Publicly available source that can be curated into machine-readable artifacts for downstream analysis.

## Current approved release
**2026** (research/review release; not production approved)

- [Transition Elements section](https://www.transitionelements.org/transition-elements/)
