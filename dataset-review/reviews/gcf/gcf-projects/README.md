# Green Climate Fund Projects API

Green Climate Fund (GCF) projects API endpoint used to access project-level records for climate finance analysis and portfolio tracking.

## Why we use it
- **Climate project coverage** - source of GCF-funded mitigation and adaptation projects
- **Finance and implementation context** - supports analysis of project status, funding, and focus areas
- **Programmatic retrieval** - API-based ingestion path for repeatable updates
- **Global portfolio view** - enables cross-country/project comparisons
