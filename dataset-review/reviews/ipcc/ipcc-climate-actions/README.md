# IPCC Climate Actions

Dataset review for IPCC mitigation and adaptation action-oriented content used to support climate action taxonomy development and action curation workflows.

## Why we use it
- Authoritative global scientific source for climate mitigation and adaptation options.
- Useful for deriving action concepts, intervention categories, and evidence-aligned terminology.
- Supports alignment of local action libraries with internationally recognized climate frameworks.
