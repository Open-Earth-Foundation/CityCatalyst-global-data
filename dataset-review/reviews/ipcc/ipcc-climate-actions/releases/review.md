# IPCC Climate Actions Review (2026-04-23)

## Scope
Initial research release to track action-oriented concepts and intervention candidates derived from publicly available IPCC materials.

## Intended use
- Build an evidence-informed action library aligned with IPCC terminology.
- Support mapping between IPCC concepts and existing city action taxonomies.
- Provide a reference layer for mitigation and adaptation action framing.

## Notes
- This release is research-only and is not production-approved.
- IPCC sources are assessment and methodology-oriented; action extraction requires curation and normalization.
- Any derivative datasets should retain clear traceability to IPCC source sections and report versions.
