# Brazil action-to-adaptation-risk mapping

This OEF research product maps adaptation actions to the vulnerability and exposure components of the six AdaptaBrasil sectors. It produces indicator-referenced eligibility decisions and component-level effectiveness inputs for a later prioritisation calculation; it does not calculate city results.

The cross-release method is documented in [`methodology.md`](methodology.md). All code, inputs, evidence documents, generated data and reviewer deliverables for the current implementation are versioned under [`releases/v1/`](releases/v1/).

## Current release

V1 is a proposed all-sector assessment awaiting human review. It is not production-approved and should not be ingested as an accepted mapping yet.
